# 毕业设计文献检索智能体提示词

本文件用于将文献检索任务分配给其他智能体。先复制“通用要求”，再复制一个专题提示词；三个专题可分别交给不同智能体。收到检索结果后，再使用最后的汇总提示词去重筛选。

已有文献可参考[参考文献索引](index.txt)和[国内外研究调研报告](国内外研究调研报告.md)。转发给无法访问本项目的智能体时，请同时提供索引内容或文献清单。

## 通用要求：每次检索都附上

```text
我的毕业设计课题是“基于 Transformer 的超视野车路协同主动避撞方案研究”，专业是数据科学与大数据技术。项目以算法为主要成果，研究车端与路侧信息支持下的遮挡场景轨迹预测、碰撞风险评估和主动避撞；使用公开数据及 CARLA 等仿真手段验证，没有真实车辆和路侧摄像头。

请依据以下要求检索和筛选文献：

1. 优先检索中国知网（CNKI），尤其是中文期刊论文和学位论文；不要求全部来源于知网。国外文献可使用出版社、学术会议、期刊官网、公开论文库及数据集或项目官方页面等渠道。
2. 如果你所在环境可以通过学校或机构授权的 IP 访问知网，请使用该机构网络已有的 IP 认证或机构登录方式。不要向我索要密码，也不要尝试绕过访问限制。如果当前环境没有机构 IP、机构权限或无法访问全文，请如实说明，并使用合法可访问的摘要及其他官方来源继续核验，不要声称已经通过机构 IP 登录或读过全文。
3. 每个专题优先寻找国内、国外文献各约一半；最终汇总也尽量保持约 1:1。以作者研究机构或论文实际研究来源为主要判断依据，不单凭中文或英文题名判断；跨国合作或来源不明的论文请单独标注并说明。相关度和可核验性优先，不为凑比例收录弱相关或无法核实的文献；如果数量不足，列出实际数量及原因。
4. 优先计算机、人工智能、计算机视觉、机器学习、智能交通信息处理等领域的研究。与碰撞风险、车辆控制直接相关的交通或车辆工程文献也可保留，但应说明它对本项目的具体价值。
5. 优先原始研究、数据集原始论文、高质量综述和正式发表的论文；有价值的学位论文或预印本可作为补充，并标明文献类型和发表状态。不限定年份，兼顾奠基文献与近年进展。
6. 逐篇给出：准确题名、作者、年份、发表场所或学位授予单位、文献类型、国内/国外判断及依据、DOI 或其他可核验标识、知网条目或其他官方来源链接、是否有公开数据/代码及其核验状态。
7. 简述研究问题、方法和与本项目的联系，说明适合引用于哪个章节或实验环节，以及主要限制；按“核心必读、可选参考、暂不建议”标记。注明实际阅读范围，例如全文、摘要或仅书目信息，不能把仅凭题名作出的推断写成论文结论。
8. 信息不足时标注“未核实”；不要编造论文、DOI、公式、参数、代码、实验结果或访问状态。区分论文报告结果与本项目尚待开展的实验，不预设本项目结果。
9. 最后统计国内、国外、跨国合作或未确定的数量，说明来源渠道和缺口，并给出最值得先读的 3 篇及理由。若已有文献清单，先检查重复；论文正文与补充材料按同一项研究统计。
```

## 专题一：数据集与轨迹预测

```text
请按照以上通用要求，筛选 8—12 篇与数据集和轨迹预测最相关的文献，尽量各半覆盖国内与国外研究。

重点检索：
- 车路协同轨迹预测及相关数据集，重点关注 V2X-Seq；
- 遮挡或不完整观测条件下，多交通参与者的轨迹预测；
- Transformer、时空图神经网络及其结合的轨迹预测方法；
- CV、GRU、HiVT 等常用预测基线，以及 ADE、FDE、Miss Rate 等评价指标的原始依据。

请说明论文是否真正研究遮挡、使用什么数据和输入、是否考虑通信延迟，以及对本项目数据处理、模型设计、基线或评价的具体参考价值。无法核实的内容请标注。
```

## 专题二：遮挡与车路协同感知

```text
请按照以上通用要求，筛选 8—12 篇与遮挡和车路协同感知最相关的文献，尽量各半覆盖国内与国外研究。

重点检索：
- 车路协同感知、协同目标检测和多目标跟踪；
- 遮挡、盲区，以及行人、骑行者等弱势道路使用者；
- 信息融合、通信延迟、丢包及坐标与时间对齐；
- 车路协同公开数据集、基准和真实场景评测；
- 检测器和跟踪器的原始论文或官方资料，例如 YOLO 系列和 ByteTrack。

请说明每篇实际使用的传感器、数据和方法，是否有支持遮挡场景的直接证据，以及对感知、跟踪、融合和实验设计的参考价值。本项目拟在统一条件下比较 YOLO26、YOLOv8、YOLO11，不预设任何检测器胜出。

请区分“路侧看到目标并提供信息”与“车端、路侧都看不到目标时对不确定区域的风险推断”，不要将后一种情况描述为已检测到隐藏目标。
```

## 专题三：碰撞风险评估与主动避撞

```text
请按照以上通用要求，筛选 8—12 篇与碰撞风险评估和主动避撞最相关的文献，尽量各半覆盖国内与国外研究。

重点检索：
- 基于未来轨迹、碰撞概率或其他指标的风险评估；
- 遮挡条件下潜在风险区域的判断，以及 ghost probe 等相关方法；
- 自动紧急制动（AEB）、自动紧急转向（AES）和制动转向协调；
- 基于模型预测控制（MPC）的主动避撞；
- 主动安全系统仿真验证、误触发和舒适性评价。

请说明各论文的适用场景、输入输出、关键假设和实现成本，以及它适合支持风险指标、控制策略、实验设计还是研究背景。区分实际碰撞、近冲突代理指标和仿真反事实结果，不要把文献结果写成本项目结果。

最后建议适合本科毕业设计的阅读顺序，区分可直接借鉴的思路与实现成本较高的方案。
```

## 汇总提示词：去重与最终筛选

将已有文献索引和上述专题的检索结果一并提供，再发送以下提示词。

```text
请作为我的毕业设计文献整理助手，对我提供的已有参考文献和新检索结果进行核对、去重和筛选。

课题是“基于 Transformer 的超视野车路协同主动避撞方案研究”，重点是车路协同、遮挡场景、轨迹预测、碰撞风险评估和主动避撞，算法是主要成果，仿真用于验证。

请完成以下工作：
1. 根据题名、作者、年份、DOI 判断是否重复；同一论文的正文和补充材料不重复计数。
2. 优先通过知网、出版社、会议或期刊官网及数据集官方页面核实书目信息。若可使用机构网络授权的知网 IP 登录，请使用已有合法访问方式；无法访问时如实说明，不得声称已读全文。
3. 以研究机构或实际研究来源为主要依据划分国内、国外；跨国合作和无法判断的情况单独列出。最终清单尽量国内、国外各半，但以研究相关度和证据质量为先，比例达不到时说明原因。
4. 优先保留计算机和人工智能方向的研究；交通及车辆工程文献如能支持风险评估、控制或验证，也可保留并说明用途。
5. 对每篇说明适合支持的部分：研究背景、数据集、感知与跟踪、轨迹预测、风险评估、避撞控制或实验评价；区分“适合论文引用”和“值得阅读但未必适合引用”。
6. 按“核心必读、可选参考、暂不建议”分类，说明取舍理由、阅读范围和未核实信息。不要为了凑数量或比例保留弱相关文献。
7. 统计国内、国外、跨国合作及未确定数量，指出覆盖不足的方向，并提供具体中文和英文补充检索关键词。

不要编造来源、DOI、实验结果或论文结论；找不到时如实说明。

以下是我的已有文献和新检索结果：
【在这里粘贴参考文献索引及其他智能体的结果】
```
