# N09 状态估计、关联与因果历史

2026年10月31日，用户明确“验收通过。继续执行n09”，即验收N08并单独授权N09；完成后停止，N10及后续未授权。实际结果、不可变被测版本和证据统一回填[节点计划N09](项目节点实施与验收计划.md#n09-状态估计跨源关联与因果历史)。本节点用构造ObservationPacket独立验收，不读真实数据或隐藏真值，不接视觉、风险决策或控制。

## 输入输出与实现规则

- `fusion/state_filter.py`：float64米制CV状态`[x,y,vx,vy]`、4×4协方差及秒差→预测/后验。F、G与技术路线21.4一致，`Q=G diag(sigma_a²) Gᵀ`；位置更新用solve与Joseph形式，矩阵对称化且拒绝非有限/非半正定输入。缺测仅外推，不刷新last_seen。默认sigma_a=[1,1]m/s²；未知位置R用diag(1,1)m²，最小特征值1e-6m²；已给R低于下限显式正则化并记录，绝不把未知R当零噪声。初始速度方差已知4、未知25(m/s)²；未知速度数值用于计算但有效掩码保持False，第二次有效位置更新后才标为估计速度。
- `fusion/association.py`：同一绝对时刻的来源状态→允许矩阵、代价/拒绝原因、匹配及未匹配行列。位置门限4m、Mahalanobis平方门限9.21；后者只是高斯起步门控，不是经实测的匹配置信率。类别已知且不同、角色/坐标参考点不一致均禁配。代价为归一Mahalanobis距离+0.2×归一速度差+0.1×归一航向差，速度尺度10m/s；缺速度/航向不伪造对应项。增加每行独占、代价1.5的未匹配虚拟列，再用SciPy `linear_sum_assignment`；其实现为[官方说明的改进Jonker–Volgenant算法](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linear_sum_assignment.html)。歧义行或列的前两候选差≤0.05时保守禁配，保留两侧未匹配目标，不声称已解决所有交叉行人关联。
- `fusion/history.py`：已可用的ObservationPacket、当前Timestamp、可选N08接收消息→统一ID目标快照、各来源状态/历史及审计。命名空间完整包含episode/source/session/sensor/local_track_id。按规范键排序，依次在不同传感器命名空间之间分配；同一传感器的不同目标不能互相合并。跨源仅合并身份关系，所有来源滤波器分别保留；输出选最新last_seen、较小位置协方差、较高已知quality及规范键确定的一个代表状态，不进行假定独立的跨源重复Kalman更新。

在线缓存保存各来源最近后验；读取快照用从该后验到now的纯预测，不把读取频率变成新观测。last_seen不递增的重复/重发/外推状态不更新滤波器、不添加历史；状态时刻倒退拒绝。原始观测时间、来源处理完成时间、state_time、last_seen和接受时刻分别保留。外部已外推的初始状态允许作为有年龄的先验，历史中注明derived_state，不能冒充在last_seen时刻采到的位置；已存在来源的纯预测包不触发测量更新。低速<0.1m/s或速度未知时航向无效，不伪造角度0。

历史最多20条、时间窗2s，缺测状态独立最多保留3s；到期显式记录淘汰原因，不能解释为风险消失。默认最多256个来源目标，超限拒绝新项并留原因，不无限积压，也不提前删未过期目标。ego单列拒绝进入障碍目标融合（ego_excluded）；坐标参考点不猜测转换。来源同一ID发生不兼容类别/参考点改变时明确重建该来源状态，原历史不混用。新episode显式清空后验、关联、历史、接收高水位及统一ID命名空间。

消息到达或usable仍在未来时，只检查头部并拒绝本次消费，不读取其目标数值。直接Packet必须已source_available；远端消息必须先通过绑定N08 ReceiverPolicy/ReceiverState的接收门控，再提取状态；不能绕过usable、TTL和会话。预测消息只提取通过原N08门控的目标状态，不读取未来轨迹作为滤波测量。字段白名单沿用N02，不增加truth_id/未来标签入口。相同身份/last_seen的冲突重复观测全部拒绝；输入排列不能改变选择。M04/M05只验融合因果/置换子范围，不代表N21模型测试通过。

## 运行、断言与产物

计划入口`scripts/check_fusion.py`，默认`configs/fusion/n09.yaml`，IDE无必填CLI，脚本覆盖和CLI可选，路径从项目根解析。首次依赖安装与运行分开；运行时不安装/下载。默认任务明示为机制诊断，不运行TFD训练或CARLA；新增SciPy锁定后回归已有节点。

必需检查：K01的(0,0,10,0)在.1s变为(1,0,10,0)；K02连续预测/小非零R更新协方差对称、最小特征值≥-1e-8、无NaN；K03连续三帧缺测last_seen不变、年龄/不确定性增长及低速航向无效；A01矩阵[[1,8],[7,2]]配对角、未匹配5且不重复；A02全门控拒绝零真实匹配并保留路侧独有目标。另验重复/倒序、episode重置、同局部ID不同命名空间、不同人禁配/歧义保留、未知R/速度掩码、历史和目标容量上限、关联排列一致、未到达/未来标签隔离、相关来源不重复测量更新及三cwd直接运行。
