## 每次开始开发前

1. 进入实际仓库，阅读根目录 `AGENTS.md`、[节点计划](项目节点实施与验收计划.md)的总规则、当前节点与前置验收结果；确认用户只授权的节点和停止位置。
2. 查看 `git status --short --branch`、`git remote -v`、当前分支和上游，检查未提交及暂存改动。保留其他电脑和用户的改动，不擅自覆盖、清理、重置或强推。
3. 联网获取对应远端的最新引用（例如 `git fetch origin`，以实际远端为准），再用 `git status -sb` 和提交比较核对本地与上游的领先、落后或分叉。远端不可达时如实说明，不能仅凭旧的远端跟踪引用宣称最新。
4. 工作区安全且分支仅落后时，使用快进方式同步（例如 `git pull --ff-only`）。存在未提交改动、分叉、冲突或不明来源提交时先检查并保护现场；不能以强推、重置或覆盖解决冲突，也不能未经授权改写已发布历史。
5. 接入硬盘，核对实际硬盘身份、盘符或挂载点、可用空间、数据目录、版本和必要哈希，并阅读硬盘内的 `数据集说明.md`。盘符或挂载点可能因电脑改变；缺盘、数据缺失或空间不足应明确失败或记录受阻，不自动下载、伪造或引用其他电脑的旧结果。
6. 同一工作分支尽量只在一台电脑进行未同步的修改。换电脑前检查并按模块提交，按该任务已有授权推送并核对远端；换到另一台后重新执行上述检查。网络不可达、未推送提交、多个工作区同时修改时明确记录，不能假设另一台已同步。

## 硬盘内容与本机路径

建议在移动硬盘建立项目专属目录，下面只是组织示例，具体名称和挂载点以实际核实为准：

```text
<移动硬盘>/OccluActiSafe/
  数据集说明.md             硬盘内维护，不提交 Git
  data/raw/                 TFD、SPD 等原始数据，保持只读
  data/processed/           获授权节点产生的处理数据
  artifacts/                审计、失败记录、实验日志和其他运行证据
  models/                   权重及其哈希、版本关联信息
```

原始数据、权重、视频、批量日志、审计产物、凭据和系统缓存不进入普通 Git；代码、项目约定与节点结果摘要由 Git 追溯。项目使用Python 3.11和仓库根目录 `.venv`，每台电脑通过 `uv sync --locked --python 3.11` 按锁文件独立准备并验证；不要把 `.venv` 当成可跨系统搬运的环境。

硬盘产物按[目录规范](硬盘产物目录规范.md)在实际artifacts根保持`产物导航.md`、`节点资料`和`公共管理`三个日常入口；各节点分最终结果、运行产物、验收证据及开发与复核，last前缀目录集中在节点01_最终结果。旧根路径为隐藏兼容链接，同一份数据没有复制，原配置、run_id、证据哈希和图片逻辑原址继续有效。当前映射与后续收尾见[最终结果目录约定](最终结果目录约定.md)及[机器可读目录表](最终结果目录.json)。换电脑或盘符变化后，按实际产物根核对/重建链接，不把旧绝对目标当数据丢失；本次只实测Windows。新增run收尾须归类并显式登记最终版，不按修改时间选最近失败任务，不提前创建后续节点。

N03的 `scripts/prepare_data.py` 已实现，运行方法和实际证据见N03专题及节点计划。后续应显式配置本机数据路径和硬盘输出目录，支持 IDE 默认配置与可选 CLI，不依赖 cwd，不自动发现或下载移动硬盘数据。原始数据只读，报告不能写进原始目录；未接盘或缺数据明确失败。目录和命令设计不代表已有代码或环境。

## 硬盘内的数据集说明

移动硬盘接入后，在项目专属目录创建 `数据集说明.md`，作为硬盘上的当前状态说明，**不提交到 Git**。本文件不记录密码、令牌、账号或其他凭据；涉及来源或许可时仅记录可公开的证据和实际核实状态。建议维护以下内容：

- 硬盘项目目录及最近一次核查日期；不同电脑的盘符变化以实际挂载为准。
- 每个数据集的名称、实际相对路径、来源链接、获取日期、版本、范围、分卷和使用条件；缺失或未经证实的信息明确标注未知。

- 审计/处理产物相对路径、run_id、代码提交、配置、运行状态（完成、失败或中断）、关键限制和复核方法；部分结果不标为完成。
- 数据只读约定、需要重新获取或重跑的事项、最近核验的可用空间及备份是否实际存在。

硬盘说明用于记录数据现状，项目结论与节点验收事实仍回填 Git 中的节点计划；不把说明写成通用变更日志。本次已接入硬盘并确认 `H:/OccluActiSafeDataset/数据集说明.md` 存在，说明已按当前真实状态维护；数据来源、哈希与完整性仍待重新核实，不据此标为就绪。
