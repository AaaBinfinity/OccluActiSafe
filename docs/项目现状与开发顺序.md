# 项目现状与开发顺序

更新时间：2026年10月30日。N01～N03 已由用户验收；N04 已单独授权实施。当前实测以节点计划为准，不推断其他电脑或服务器的状态。

## 1 课题与交付

课题面向建筑、大车、停放车辆等遮挡导致的盲区风险，研究用车端和路侧历史观测预测交通参与者未来运动，再比较本车动作风险并主动避撞。数据路线为 V2X-Seq TFD 真实轨迹预测、SPD 真实图像车路感知及感知到预测验证与 CARLA 闭环；没有真实车辆和摄像头，实车部署不在当前交付范围。

最终交付以可无界面运行的 `occluactisafe` 算法包为核心。主方案由路侧负责感知、融合与协同预测，并向车端发送目标状态及预测轨迹；车端检查消息并完成最终风险判断、AEB/AES、MPC 与回退。车内视角与辅助界面服务解释和评测。建筑遮挡来车、行人和骑行者鬼探头是必做案例，两车意图协调排在核心单车闭环之后。

## 3 编码前先固定的约束

- 输入使用决策时刻已可用的历史观测。消息分别记录采集、到达、解码校验完成时刻，保持绝对预测起点，检查有效期与剩余覆盖。
- 隐藏真值与未来只用于标签、评测或明确隔离的上界实验；双方都看不到的区域表示未知，不能伪造目标或安全通行结论。
- 风险绑定候选动作、参考策略和未来时域；实际碰撞、近冲突代理、仿真反事实分开记录。
- 新增行人/骑行者时同步适配类别、短历史、定位、动力学与几何，不能只扩充检测类别便宣称完成。
- 每个实现阶段先通过可手算夹具与因果边界检查，再进入复杂模型或批量仿真；每个独立改动立即做必要检查和中文提交。
