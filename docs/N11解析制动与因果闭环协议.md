# N11 解析制动与因果闭环协议

2026-10-31用户验收N10并仅授权N11。实现范围为纵向S曲线、CV/TTC和原始风险AEB、正常/减速/降级与不可避减损、固定步长解析配对；不创建CARLA、AES、MPC模块。最终实测回填同一节点计划，不以构造机制证明真实避撞。

`planning/braking.py`精确积分分段常jerk，输入v≥0、a、B>0、J>0及排队控制前缀，输出各段和任意时刻s/v/a/j。三段公式按详细技术路线21.9；a<-B、v<a²/(2J)且a<0等非法停车边界拒绝，不clip负速度。延迟期必须传播已有控制，只有a=0匀速测试才加v*delay。停车后保持s和v=a=j=0；剖面不等同真实执行器标定。

`control/executor.py`只执行一个纵向剖面，同一请求的pending计划不每帧重置延迟；升级制动时保留不可取消的排队前缀，由未来生效状态生成新剖面。`fallback.py`提供明确的低速/信息不足制动请求，异常无结果不能批准正常通过。无转向执行。

`planning/candidates.py`生成保持/减速/紧急制动的给定路径，复用N10模式评分；候选位置采用精确剖面采样，声明分段线性几何模型，不能将其当真实动力学连续安全保证。`compute_ttc_cv`只读当前合法位置/速度，复用N10区间几何，净距10m闭合5m/s得到2s±.01s；无接触返回None，不用Infinity。时域默认3s；完整停车超过3s必须滚动检查。

`decision.py`使用夹具门槛raw_score=.5、TTC=2.5s，非校准概率或正式安全阈值。高风险AEB锁存至停车，防止重规划使制动起点后移；未知区域/短覆盖/已知目标缺失只能降级，不能由空预测推出安全。候选均有风险或受硬约束否决时标记no_safe_candidate_found并选择减损，不能报告安全轨迹。C08仅验纵向候选及无安全候选子范围，左右AES选择留N24。

路侧只接收当时可用SourceTrack，通过既有CV状态外推生成N02预测；N08信道计入到达/可用时刻，V端复用接收会话/序号/TTL/年龄检查，不把arrival变为anchor，已知ID缺预测保留gap。车辆决策核心只接收观测和合法消息，不接收场景隐藏对象/未来轨迹。解析环境独立持有真值，负责按声明可见距离产生当前观测与事后接触事件；碰撞检查不反馈给当次动作选择。

默认固定场景为直路静止遮挡目标：初始车速12m/s、车体4×2m、目标中心35m（足够制动）或8m（物理不可避压力）。仅车端可见距离8m，路侧从起点可见，信道延迟.2s、执行排队延迟.15s；未知时采用B=1.5/J=4的谨慎制动，AEB共享B=4.5/J=8。上述距离与参数在运行前固定，不按结果更换。无干预/仅车端/协同 × TTC-AEB/预测风险AEB分别记录，同场景初始状态及外部扰动一致；控制后各分支自行积分，不强行回放他支未来。

必需C02检查21.175m≤1e-6、负初加速度、三角/梯形/停车保持与非法边界；C03回归N10对称/旋转/边接触/区间穿越；F01因果部分检查未到达/过期不改变动作、前缀与初始条件配对、确定性重放、未知区降级、互斥控制/有限值/无抖动。每步保存观察/发送/到达/采用/风险/候选/动作/执行轨迹、分段参数、接触及碰撞时速度（本车/相对）、失败原因。预测几何风险、解析世界几何接触、近冲突代理与CARLA实际事件分字段。

默认IDE入口`scripts/run_analytic_demo.py`，路径不依赖cwd，CLI可选。原始CSV/JSON/失败证据在硬盘，中文PNG/SVG在项目docs/过程图并记录来源哈希；缺路径或依赖明确失败，不自动安装/伪造。N11完成后停，N12仍未授权。
