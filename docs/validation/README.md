# 核查记录说明

保留4份有实际依据的原始核查JSON，分别记录参考代码/解析算例、通信方案、辅助界面与车内视角材料的有限检查。它们只支持当时记录的结论，不代表当前已运行算法或闭环。

文档静态检查默认直接运行，不为每次检查积累备份或报告副本：

```sh
python3 scripts/check_docs.py
```

检查范围是Markdown/HTML相对资源与HTML锚点、JSON语法、4份图集清单中的哈希，以及仍保留的5张概念PNG的文件头尺寸。12张流程图统一保留SVG，额外PNG、旧QA和重复静态报告已清理；过去版本通过Git追溯。

远程URL只计数，不联网；不检查Markdown标题锚点、CSS或动态链接，不评估排版，也不运行算法、训练、UDP或CARLA。依赖缓存与仓库根的大型数据/产物目录跳过。

需要保存正式核查证据时可显式指定 `--output` 写入新文件；普通整理任务只保留Git提交与终端检查结果。原53项及B类算法/系统测试仍待实施。
