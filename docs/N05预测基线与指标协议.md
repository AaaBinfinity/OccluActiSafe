# N05 CV基线与预测指标协议

本节点只实现离线轨迹预测与评分，结果及验收事实统一见[节点计划](项目节点实施与验收计划.md#n05-cv真实轨迹基线与统一预测指标)。N04已获用户验收；原始坐标一致性及稀少类别监督限制继续保留，不据此声称训练就绪。

## 输入、算法与输出

`prediction/baselines/cv.py:predict(history,timestamps,mask,*,future_times,anchor_time=0)`输入未归一化米制位置[N,H,2]、实际时刻[H]及有效位置mask[N,H]；历史不能晚于anchor。每个目标以最后两次有效观测位置差除实际时间差求速度，再从最后观测时刻外推到anchor及未来格点；缺失中间帧不缩短分母，不读取监督或其他目标未来。输出positions[N,1,F,2]、velocity、valid、last_seen_time及K=1。静止输出静止，转向沿最后线段；一点或全缺失无可估速度，valid=False，有限零占位不能当作有效预测。离线N04窗口不设额外过期阈值，旧位置会外推到anchor；不据此宣称在线适用。

`predict_state()`供状态时间机制检查：用state_time继续外推，last_seen_time保持最后真实观测时刻。t=0观测x=0/v=10，state_time=.2/x=2，anchor=.3得x=3，不能得5。

## 评分对象与单位

默认读取N04已冻结的完整model_val角色，H=50、F=50、dt=.1s，历史跨度4.9s，未来5s。项目地理分组留出不称官方test。主评分对象沿用N04：历史TARGET_AGENT且历史/未来全部有效；所有历史TARGET_AGENT都写逐目标表，不完整者保留ineligible与有效未来点数，不能默默删掉失败预测。类别为最后历史类别，BICYCLE不自动称为CYCLIST。文件内ID不是跨文件独立物理目标。

`evaluation/prediction_metrics.py:score_target()`支持[K,F,2]与未来mask。先按logits稳定降序选top-K；无logits按显式模式顺序。ADE为最高权重模式在有效未来格点的欧氏距离均值，FDE为最后有效未来点距离；minADE/minFDE在top-K内分别取最小值，可能来自不同模式，只用于离线评分。CV仅K=top-K=1，ADE=minADE、FDE=minFDE。MissRate定义为minFDE严格大于2m的目标比例；2m是本次固定的开放环诊断阈值，不是风险/安全阈值，也不声明复刻官方评分器。

逐目标等权汇总，单位为米；无标签不进入评分分母；缺预测计miss且显式报告missing_prediction。误差均值以scored为分母，MissRate以scored+missing_prediction为分母；缺预测不能在误差分母外消失而不报告。有效GT或有效预测非有限明确失败，无效GT槽可为NaN。全无可评分对象返回null，不冒充零误差。当前实现不生成置信区间、模式概率校准或碰撞指标。

CV直接用原始局部米制位置，不经过scaler；局部坐标由刚体平移/旋转得到，欧氏距离与还原世界坐标后相同，机制测试检查误差≤1e-8m。N04中原始坐标的物理一致性仍未解决，米制数值结果不能证明标注正确或道路预测可信；保留全部原始异常，不裁剪、不删样本、不按结果改组。

## 运行与保存产物

IDE选择仓库`.venv/Scripts/python.exe`，直接运行`scripts/evaluate_prediction.py`；默认`configs/models/cv.yaml`，`OVERRIDES={}`，CLI可选。YAML→显式脚本覆盖→显式CLI，False/0保留，相对路径基于仓库根，import不执行。首次安装、硬盘核对与日常评测分开，不安装依赖、不下载数据/权重。缺数据、标签、依赖、划分哈希不符或无窗口明确失败。小规模`max_windows>0`只能称limited。

默认与本次实际运行不打开risk_calibration/test标签；test还要求allow_test=true及规范化完整任务配置（去掉frozen_config_sha256自身）的SHA-256与冻结字段一致。该程序开关不能替代节点授权或正式实验预登记，本次未运行独立test。

`prediction/evaluate.py:run(config)`先验证N04完成与冻结分组、索引角色，再逐文件读取输入、运行CV，之后才打开监督评分。每个run保存manifest、task_config、per_agent_metrics.csv、predictions.csv（目标×未来格点、mode=0、无效位置留空）、metrics.json、input_inventory.jsonl（每个输入/监督文件SHA-256）、evidence_index.json、status.json。汇总包含类别/视角分母、有效/缺预测数、排除原因、预测CPU耗时及总墙钟时间；耗时不纳入确定性对照。失败run保留failed状态及已有部分产物。

测试入口：`python -B -m unittest discover -s tests/unit -v`。N05的10个测试覆盖M06全部本节点断言、静止/转向/短历史/全缺失、状态时间、手算top-K与mask、缺预测分母、坐标还原、配置/封存开关、机制端到端重跑与缺监督失败、三cwd无必填CLI。夹具只证明软件机制；真实完整验证与确定性重跑另列节点计划，不把两个重复run算独立样本，也不提前宣称完整M01～M08通过。
