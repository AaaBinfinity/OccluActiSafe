## 直接运行

在项目终端运行，无须每次编辑配置文件：

```powershell
.\.venv\Scripts\python.exe .\scripts\train_n17_local.py
```

IDE直接运行上述脚本或[原优化配置入口](../configs/experiments/n17_local_fast.py)也会打开同一菜单。输入按以下顺序：

1. 选模型编号1～15，或完整名称，例如YOLOv8n；三族n/s/m/l/x均保留，不预设胜者。
2. 输入seed，例如17、29或43；合法范围0～4294967295，单seed不代表完整三seed比较。
3. 输入SGD初始学习率lr0，例如0.001、0.0003或3e-4；必须有限且0<lr0≤1。
4. 输入batch；优化配置按n/s/m/l/x给出32/4/2/1/1起点，切换型号自动更新，显式输入优先。此前实测采用其他资源配方；当前batch32/worker2组合先probe，不预设容量合格。
5. 选择check、plan、probe、train或resume。操作始终默认check；选择resume还需输入含本机训练任务.json的原任务根目录。
6. 查看模型、seed、学习率、batch/nbs、workers、CPU/验证batch、300/15/10早停与输出目录摘要，输入y确认。空确认、q、Ctrl+C或输入结束均取消，不预检或训练。

例如准备运行YOLOv8n/seed17/lr0=.0003/batch8，依次输入`2 → 17 → 0.0003 → 8 → 4 → y`；其中4是train，最后y会开始真实新任务。只想看菜单与参数，可在命令末尾加`--dry-run`，即使选择train也只展示。当前默认学习率仍为0.001，选0.0003才覆盖，候选学习率不代表模型已达标。

完整指标、中文图集、weights仅last.pt/best.pt和原早停继续保留；数据、图、权重及原始选择JSON均写H盘，不推普通Git。交互不替代GPU/输入检查或模型准入。

## 非交互与预览

显式CLI参数保留，适合批处理；本次选择不会回写默认配置：

```powershell
# 只解析和显示下面的参数，完全不预检/训练
.\.venv\Scripts\python.exe scripts/train_n17_local.py --model YOLOv8n --seed 17 --lr0 0.0003 --action train --dry-run

# 固定参数，仅冻结计划并做原生解析/输入预检，不训练
.\.venv\Scripts\python.exe scripts/train_n17_local.py --model YOLOv8n --seed 29 --lr0 0.0003 --action plan
```

没有模型/seed/动作等覆盖参数时默认交互；`--interactive`强制菜单，`--no-interactive`显式按配置/CLI执行。CLI显式train表示调用方已选定训练，不另开输入提示；内部独立预检参数先分流，不递归打开菜单。直接运行原n17_local.py时菜单以该文件的默认值为起点，原文件内容不改；普通脚本默认采用优化配置。IDE控制台需要支持input，读不到输入时明确取消，可改用IDE终端或显式CLI。

## 输入、实现、断言与产物

`detector_local.local_options`从同一字节快照读取配置，新增LR0可选项，缺省仍0.001；`selected_options`只在已捕获字节上重新应用本次选择，交互期间编辑默认文件不串改本次任务。LR0真实写入training.lr0并进入原训练配方哈希，不是只改显示；改模型按BATCH_BY_SCALE更新起点，显式batch覆盖优先，旧无此映射的文件保留原batch。实际nbs仍等于batch，统一FP32/batch1评分与门槛不改。

`detector_terminal.choose_options`负责纯文本输入/范围检查/摘要/确认，确认前不调用执行器；`execute_options`将实际选择、默认源码SHA、有效参数SHA和完成/失败状态写入N17/03_验收证据/n17_terminal_selection_<uuid>/终端任务选择.json。真实训练另外沿原逻辑冻结完整YAML、有效选项、权重和源码身份。仅计划/取消/失败不能当训练完成或提升为训练last；恢复仍需同模型/seed/数据/配方/源码/GPU，不能用新入口绕过旧检查点约束。

必需测试：15型号与尺寸batch、seed/lr数值边界、无效输入重输、缺省检查、空确认/q/EOF/Ctrl+C取消、续训路径、交互期间文件被编辑仍用原字节、LR0进入实际training与配方哈希、CLI预览不触发GPU、内部预检不弹菜单、选择落盘和执行失败保留；补跑原N17及受影响N16回归。另用真实终端做train参数预览/取消和异地CLI仅计划，核实实际冻结学习率，不用机制mock代替真实训练结论。

终端验证保存原始输入/输出与来源SHA，适用可视化为真实文本的中文PNG/SVG排版，明确不是系统窗口截图；本次不训练，因此新增loss曲线/权重/模型指标不适用。被测提交、真实环境、检查四类数量、run_id与证据最终回填同一[节点计划N17](项目节点实施与验收计划.md)。
