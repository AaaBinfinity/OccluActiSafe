# N10 分类几何、覆盖与未知区域约束

2026年10月31日，用户明确“验收通过 继续完成n10”，即验收N09并仅授权N10。实际版本、必需检查、指标和证据回填[节点计划N10](项目节点实施与验收计划.md#n10-分类几何未知区域与原始风险)；完成后停止，N11及后续未授权。不实现AEB/MPC、动作生成/选择、像素感知或CARLA。

## 几何与区间

`risk/obb.py`定义以几何中心为参考的OBB/圆，位置m、尺寸m、航向rad；车辆和骑行者用声明长宽的OBB，行人用显式声明半径的圆。SAT检查双方方向轴；矩形/圆使用局部坐标最近点，圆/圆使用圆心距。尺寸必须正且有限，裕量非负，数值epsilon=1e-6m，边界接触按风险口径相交。后轴参考点必须显式给出已知中心偏移并复用N02坐标函数；不猜真实尺寸、偏移或无效航向。

`perception/participants.py`作纯几何类别分派与N02 SourceTrack适配；未知/缺尺寸、缺OBB航向明确拒绝，不丢弃该目标后批准通行。行人半径为显式模型假设，不把汽车长宽直接套给行人。

`risk/occupancy.py`接收声明的绝对时间轨迹：中心分段线性、航向最短角差插值，严格时间递增，掩码不跨洞补值、不外推。按双方所有时间结点拆段，以每段插值模型的实际中心速度和角速度上界，在中点将每个形状膨胀`(v+r*omega)*dt/2`。可证分离才排除；否则二分到dt≤.01s。仍不能排除时返回potential_overlap/uncertain_interval；样本上的几何重叠与仅有区间潜在重叠分列，均不是实际车辆碰撞。预算耗尽也只能保守返回未排除，不能返回安全。给定曲线不是动力学可行性证明，不拼接位置/时间跳变来冒充可达路径，实际可执行性由后续节点复核。

## 绝对覆盖与模式分解

`risk/coverage.py`与`multimodal.py`：候选输入明确candidate_id、reference_policy、完整前缀和给定路径；不是在N10生成控制动作。所有候选共用同一plan_start和目标共同有效区间，默认请求未来3s。每个相关目标、每个正权重模式按连续有效部分求终点；有效期/信息年龄检查在采用时刻执行，与future_end分开，不以重发刷新信息或把anchor改为arrival。剩余4/2.8s时全部候选统一按2.8s评分，coverage_complete=False；缺失/过期的已知目标记gap，不悄悄从分母消失。

当前时刻至plan_start的排队控制前缀单独检查；缺覆盖或前缀潜在接触均阻止仅凭后续低分正常通过。模式权重非负、有限、和为1；空模式/非法尺寸/NaN拒绝。同一模式多时刻命中只计一次，目标原始评分为命中权重之和；多目标输出R_max与截断和R_sum，不能当精确联合概率。风险分解记录对象、候选/参考策略、实际时间窗、模式、几何与区间原因，risk_kind=uncalibrated_score；calibrated_event_probability和实际/仿真真值事件均为None，不实现N23校准。

N02预测消息适配只采用已到达且可消费的接收记录，复用N08接收门控；单时刻可用检查不替代3s覆盖。OBB默认适配声明的恒定来源航向，仅代表该预测几何模型，显式标记假设；不把未来真值或模型轨迹当观测。已知目标注册表可从N09有限记忆取得；存在已知ID却无预测时coverage gap必须可追溯。

## 可见性与未知区

`perception/visibility.py`用已知地图/合法可用遮挡物OBB、当前传感器位置/FOV/范围/质量建立平面网格，默认分辨率.5m。对网格中心作射线与OBB的解析相交检查，区分几何可视、遮挡、未知，并单列已知占用；不读取隐藏目标轮廓、GT或未来观测。网格中心近似不是三维/整格检测完整性证明。

几何可视不等于已确认无人。只有带来源与可用时刻的显式自由空间证据，且在该来源当时可见区域内，才可标记已证空；默认没有这种证据。未知/遮挡/缺证空单元产生区域约束，不生成位置精确的隐藏目标。`OcclusionRiskRegion`保存区域、来源、参考时间、类别假设与可达半径；按单元包围半径+v_max*age+.5*a_max*age²+声明目标半径扩张。起步vehicle/pedestrian/cyclist速度上界15/2/8m/s、加速度3/1/2m/s²，仅为构造机制假设，未标定为真实安全上界。

已知不可行候选、地图边界/占用冲突、未知可达约束、缺覆盖等输出normal_blocked及原因；False只表示本模块未触发这些否决项，不批准任何控制动作。地图ROI外入口未覆盖时显式记outside_domain_unknown；只有封闭机制域的明确假设可消除此项，不能由空检测推出。区域约束、已观测目标原始评分和未来校准概率分字段。

## 必需断言、入口与证据

G01～G05全部适用纯几何断言；R01～R03的.7权重、(.7,.4)多车口径及4/2.8s共同窗口；B02固定墙体/可用观测时改变不可用或隐藏信息不改变当前几何输入输出；B05行人圆、骑行者OBB、后轴参考与穿越边界；B07本节点仅几何硬约束、消息覆盖缺失/异常声明的否决子范围。求解/控制回退、实际残余碰撞及完整B07仍待N11/N24/N25等，不提前标通过。

入口`scripts/check_risk.py`默认`configs/risk/n10.yaml`，IDE无必填CLI、覆盖及CLI可选、路径从项目根解析。默认明确为构造几何/风险机制，不读TFD/test/calibration、不训练、不启动CARLA或执行控制；不需新增依赖。

保存原始场景/几何、区间细分轨迹与事件、模式评分分解、共同覆盖报告、可见/占用/证空/未知网格、区域约束和失败状态；自动输出PNG/SVG及CSV/JSON来源哈希。保留边界与保守近失样例，不伪造实际碰撞。运行产物及中文过程图片在移动硬盘，Git只存源码、配置和摘要；本节点无优化训练步，开发诊断按实际几何/区间逐步留存。
