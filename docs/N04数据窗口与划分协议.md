# N04 数据窗口与划分协议

本协议于2026年10月30日在查看预测性能前冻结，执行入口为 [节点计划](项目节点实施与验收计划.md#n04-分组划分因果特征与样本窗口)。N04仅准备数据，不训练、选择或评测预测模型，也不产生风险事件标签。

## 输入范围与分组

- 输入是N03已审计的本地TFD，原数据只读；每个实际制窗文件重新计算SHA-256，与N03清单比较，不匹配即失败。
- 全部轨迹文件先登记到`split_manifest.json`。按原始`city:intersect_id`、明确录制ID（如有）、基础episode的连通分量分组，再制窗。同地理标识的全部episode、视角、重叠窗口及分支继承同组。当前数据没有已核实的原始录制ID，地理标识也不等于地图文件ID；不得由文件编号推断地图对应关系。实际制窗时复核每行地理标识，跨地理文件明确失败。
- 固定seed=20261030，按SHA-256(seed:group_id)排序。train/model_val/risk_calibration/test的目标组比例为0.65/0.15/0.10/0.10；每类先分配1组，剩余组按比例及最大余数法分配。比例针对组，不承诺文件数比例相同。不读取标签或性能选择分组。
- 原始train/val目录身份单列。项目四集合仅从原train形成；原val/test隔离，不进入项目拟合或评分。项目留出集不能称为官方测试集。少于4个合格组明确失败。
- 本次完整声明的历史输入范围为`single-vehicle/trajectories`与`cooperative-vehicle-infrastructure/vehicle-trajectories`两类原train文件。两者具有AV参考轨迹。其他视角仍完整登记和分组；缺少AV参考的路端视角及未核实因果性的融合轨迹不作为本协议的历史输入。不存在的地图映射、信号或路端来源不补造为已观测值。`max_files=0`处理全部声明范围，正数仅是每角色限量接通，产物明确标记limited。

## 窗口、时间和监督

`build_causal_window()`输入显式带clock_domain、observation/source_available/arrival/usable_time的记录与合法参考位姿，先检查时间顺序及决策时可用性，才读取历史坐标。到达不代表可用。未来目标不能增加当前目标列表。参考位姿应由当时可用本车定位提供。

TFD适配模式明确为`offline_annotation_history_reference`：采集、源可用、到达和可用时间均假设为原标注时间，只用于离线历史参考，不声称这些是真实在线处理或通信时间，也不声称标注生成过程已获因果核验。原始秒级时间用Decimal减去该文件最早时间，再转相对秒，避免大绝对时间的浮点差分。每文件生成一个可变目标数场景；ID仅在该文件内有效。

默认H=50、F=50、dt=0.1秒，决策点为文件最早时刻+4.9秒。历史格点0～4.9秒，未来5.0～9.9秒，即未来时域5秒，保留TFD采样长度。20/40仅用于CARLA设计的机制夹具，N04没有建立CARLA任务。缺格点不插值；位置/特征掩码为False，零只作占位。`actual_dt`记录同ID相邻真实观测间隔，不能当成每个格点都有新观测。

白名单特征依次为局部x/y（米）、vx/vy（米/秒）、ax/ay（米/秒²）、sin/cos航向、长宽（米），另存观测掩码、类别、历史TARGET_AGENT标识及时间。可靠原速度优先，否则用同ID过去相邻位置差分；加速度用过去相邻速度差分。无先前点不伪造速度或加速度；低速小于0.2米/秒时不采用航向特征。所有缺值均有feature_mask。

坐标锚为决策点前最后合法AV位置；优先原始航向，缺失时用过去运动方向（速度至少0.2米/秒），否则明确采用世界轴参考yaw=0，不能称为真实车身朝向。每样本索引保存实际锚方向依据。

`labels.py`仅生成同源未来位置和future_mask。输入`.npz`与监督`.labels.npz`物理分离；`PredictionDataset.inputs()`不打开监督文件。监督中的`target_eligible`要求历史TARGET_AGENT且完整50点历史与50点未来；未来不齐和历史不齐的上下文目标仍保留掩码，不删除样本来改善指标。N04不判断实际碰撞、近冲突代理或仿真反事实。

## 统计量、入口与证据

`MaskedScaler`仅接受role=train及有效历史特征，以可合并均值/二阶矩累计；忽略未知字段和无效槽。保存有效计数、均值、总体标准差、空特征及规范JSON哈希；零方差/空特征scale=1，变换后无效槽仍为0。model_val/risk_calibration/test无法更新统计量。

IDE直接运行`scripts/prepare_windows.py`，默认配置`configs/data/n04.yaml`；脚本`OVERRIDES`与可选CLI依次覆盖。相对路径均从仓库根解析，import不运行任务。缺盘、缺N03就绪复核、哈希不符、无有效训练统计或空间不足均明确失败；运行任务不安装依赖。默认6个进程，索引分批读取，按文件流式保存，低于10GiB剩余空间停止并保留部分证据。

运行目录在移动硬盘，包含manifest、任务配置、split_manifest、split_audit、selection、train-only scaler、逐分区样本/索引/统计与状态。index逐文件记录原始行数、角色、输入哈希、有效槽及监督对象数。N04实际结果与限制只在同一份节点计划回填，不以本协议代替验收事实。

测试`test_n04.py`覆盖D02/D03/D04及M04预处理子集：两ID差分、未来及未来新增目标隔离、三策略分支/视角/重叠窗口分组、训练统计隔离、20点跨度、缺测与合法零值、arrival/usable区别、锚坐标与输入/标签分离。`test_n04_pipeline.py`用8个明确构造场景检查完整入口、原始数据哈希拒绝、配置覆盖、import无副作用及三种cwd无必填CLI。夹具证明机制，真实数据运行单独报告；M04模型forward、图和地图断言属于后续对应实现，N04不宣称完整M04已通过。

本机完整运行与最终必需软件检查已完成，N04待用户验收。实际训练输入存在严重坐标不一致疑点：同文件AV和其他目标的原始位置可相距约186万米，最大局部坐标分量约183万米，原因未定；不能以有限数值直接认定物理坐标一致。原始值和全部样本保留，未按数据表现新增距离裁剪或修改归一化算法。完整 TARGET_AGENT 行人监督仅2、校准和测试均0，BICYCLE完整监督82且不等同已核实骑行者。当前软件断言通过，正式训练适用性未确认，实际原始行与分母见节点计划和硬盘证据。输入哈希针对归一化前白名单历史内容，归一化版本由独立scaler哈希关联。
