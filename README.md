# OccluActiSafe

**Occlusion-Aware Active Safety for Cooperative Driving**

毕业设计课题：基于 Transformer 的超视野车路协同主动避撞方案研究。

核心交付是可脱离界面运行的车路协同主动避撞算法包。路侧补充盲区观测并进行协同预测，车端负责最终风险复核、AEB/AES 决策和控制；CARLA 与车内视角、辅助页面用于验证和展示。建筑遮挡来车及行人/骑行者“鬼探头”均为必做场景。

项目与远程仓库名为 `OccluActiSafe`，拟建 Python 包名为 `occluactisafe`，预测模型工作名为 `RC-STGT`。

## 当前阶段

截至 2026年10月26日，仓库处于文档整理阶段，已包含研究方案、技术设计、图源、概念图和历史核查记录。算法包、模型训练、通信服务及 CARLA 闭环仍待实施。工程框架先写入Markdown供审核，待用户明确授权开始编码再创建工程文件。检测器须统一比较YOLO26、YOLOv8、YOLO11及有必要的其他候选，按本项目实测结果选用，不预设胜者。53 项正式测试与 B01～B08 补充测试是规格；概念图中的数值不能作为实验结果。
